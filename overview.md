# REQUEST OVERVIEW

> SIMPLE, INTERACTIVE CLI MENU THAT UNPACKS DIRECTORIES WITH LOTS OF ZIP FILES

## IN OPERATION

- Interactive CLI called with `dumpie`
- once `dumpie` is typed, in the terminal the CLI should greet the user, then prompt for a path.
- The user then provides the path, and the CLI will unpack ALL zips, create and place them into a folder of the same name.
- WHEN THE PROCESS IS COMPLETE, A NEW FOLDER SHOULD BE CREATED IN THE SAME PATH THE USER PROVIDED; ALL ZIP FILES SHOULD BE MOVED INTO THIS FOLDER TO ISOLATE THEM AS PROSESSED, UNPACKED AND ARCHIVED.
- WHEN ALL IS COMPLETE, THE CLI SHOULD CONFIRM COMPLETE BY PROVIDING BOTH THE PATH THE USER ORIGINALLY GAVE IT, AND A PATH FOR THE ARCHIVED ZIP FILES.
